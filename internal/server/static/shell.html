Session

Commands run as root on the endpoint. That is the same authority a software package already carries — this is just a faster path to it — so every command is written to the audit log with who ran it before it is sent, and a command that hangs the agent still leaves a record.
No session open. Choose an endpoint and open one.

Up and down arrows walk your command history. cd is handled by the session rather than a subshell, so it persists between commands the way you would expect.

Open sessions

Sessions that have not been closed. You can resume your own. A session belongs to whoever opened it; an administrator can take one over, which is recorded in the audit log as a takeover. Closed sessions, and every command run in them, are under Access → Sessions.
