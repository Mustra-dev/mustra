Reports

Everything in mustra is already exportable, which is not the same thing. An export is a stream of rows for a machine; a report is a page for a person — sections with titles, counts rolled up, and the date it was true. Renderings are kept rather than regenerated, because the point of a monthly report is being able to say what the fleet looked like on the first: re-running today's query against today's data answers a different question.
