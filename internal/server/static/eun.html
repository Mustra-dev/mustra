Messages

What the person at the endpoint sees. A notice tells them something; a restart asks them to do something disruptive, so it negotiates — a countdown, a deadline, and a bounded set of postponements. Answers come back as a deployment, so "who did we tell and what did they say" is the same question as "who did we patch and did it work".

Restart options

The gentle warning is what stops a restart prompt being the first anyone hears of it. Postponement options are deliberately a fixed list rather than a free-text box — "remind me later" with no bound is how a machine goes unpatched for a month.

Buttons

Left off, the window shows the usual choices for this kind: Got it on a notice, Restart now plus whatever postponements you allowed on a restart.

A label is yours to write; what the button does comes from a fixed list, so an answer still means one thing when you report on it later. At least one button has to dismiss the message — otherwise the person at the endpoint gets a window they cannot close.

Sending creates a deployment, so the answers land beside every other endpoint outcome. Offline endpoints are skipped rather than queued — a notice is about something happening now, and one that arrives whenever a laptop next wakes is worse than none.
