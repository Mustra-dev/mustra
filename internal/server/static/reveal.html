How this works

A rule names patterns, roots and endpoints. The agent walks the files on the endpoint, runs the patterns there, and confirms matches with validators — the Luhn check for card numbers, the Social Security Administration's rules for SSNs, mod-97 for IBANs — so a version string with sixteen digits is not a finding. What comes back is the path, the size, the modification time and a masked snippet. The file's contents never leave the machine. Office documents (docx, xlsx, pptx, odt, ods) are read; PDFs and binaries are not.

Rule sets

A regime as you actually work in it: a few rules aimed at a few groups, turned on or off as one thing. Saving a set writes its targeting and its enabled state onto the rules it names, so the Rules tab never disagrees with it — there is still one answer to where a rule runs. Deleting a set disables the rules it turned on, because a scan nobody remembers asking for is worse than no scan.
