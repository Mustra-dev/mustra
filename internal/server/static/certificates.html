New certificate

Issue a certificate and install it on a server in one go. The server makes its own private key (it never leaves the machine), the authority you pick signs it, and the agent writes the files, reloads the service and checks the service now presents it — putting the old one back if anything fails. Once installed it shows up under Inventory and is renewed automatically before it expires.

    Expiry alerts
    
        
    
          Mustra checks every hour and announces each certificate or credential once as it crosses each threshold — in the
          console's notifications and to every integration that takes expiry events (Teams, Discord, Slack, a webhook
          for your own automations, ServiceNow incidents). Renewing it gives it a new expiry, and its alerts start over.
        
    
        
    
          
    
          
    
            
    
            
            
    
        
    
        
    
        
    Changing alerts needs the Settings permission.

          take every threshold, or only some — for example one ServiceNow incident per item at 60 days, and a Teams message
          at every step.

    Trusted roots
    
        
    
          Put a certificate authority's root into every endpoint's trust store, so the certificates it signs open without
          a warning. Every endpoint also covers endpoints enrolled later; Remove takes it back out. Linux and
          Windows change their own store; Macs only trust a new root from an MDM profile, so they go through Fleet. Browsers
          with their own store (Firefox) are not covered.

    Certificate authorities
    
        
    The authorities Mustra can get certificates from. Each one below says what it is for.
    
        
    
          
    Mustra Private CA
    For internal names and addresses (pi.hole, a Proxmox node). Free, renewed as often as you like, trusted wherever its root is installed (see Trusted roots). Nothing to set up. Download the root certificate.
    
          
    Let's Encrypt
    Publicly trusted certificates for names under your Cloudflare domains; ownership is proved with a DNS record through the Cloudflare API. Needs the account email and a Cloudflare token below.
    
          
    Cloudflare Origin CA
    Certificates only Cloudflare's proxy trusts, for servers behind it. Needs the Cloudflare token below.
    
          
    Active Directory Certificate Services
    Your domain's enterprise CA, which domain-joined Windows machines already trust. A Windows endpoint in the domain (normally the CA server) submits each request and carries out revocations, so its computer account needs Enroll on the template and Issue and Manage Certificates on the CA.
    
          
    Tailscale
    A publicly trusted certificate for an endpoint's own tailnet name. Needs HTTPS certificates turned on for the tailnet; cannot be revoked from Mustra.
