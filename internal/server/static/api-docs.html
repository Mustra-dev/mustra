OpenAPI 3.2 specification
Import it, as JSON or YAML, into Postman, Insomnia, Bruno or any OpenAPI code generator. It is generated from the running server, so it is always current.

Call the API with a token from Administration → API Tokens, sent as Authorization: Bearer <token>; a token can do only what its permissions allow. The examples read it from the MUSTRA_TOKEN environment variable so it never ends up pasted in a script. Open a route to build a request: fill in its path parameters, query string and body, pick a language and copy the code. Where the spec describes a route, its query parameters and body fields are filled in from the schema and its responses are listed.
