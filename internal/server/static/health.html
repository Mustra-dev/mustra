Endpoint health

Each endpoint samples itself every 15 seconds and keeps the samples locally; only a summary travels, so the server stays an inventory rather than becoming a metrics store. A category scores 100/(1+events), which makes the first bad event expensive and the tenth nearly free — matching how people actually reason about repeated problems. An endpoint that hasn't reported scores nothing rather than 100: no history is not a clean bill of health.

Risk by endpoint

Risk asks a different question from health: not "is this machine working" but "what would it cost us if this one were compromised". Known vulnerabilities, missing patches, whether mustra can even manage it, and whether it's reachable — each capped so no single factor saturates the score — then multiplied by how much the endpoint matters. The same vulnerability on a domain controller and on a spare laptop are not the same finding, and a number that treats them alike is one nobody trusts.
