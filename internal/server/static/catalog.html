Offered packages

The software packages Self Service offers on endpoints. A package reaches the computer groups in its scope — leave the scope empty and every machine sees it — on the platforms listed: those where the version Self Service installs has an install that needs no parameters. A machine's architecture, distribution, OS version and the package's requirements can still rule it out. To offer a package, or change how it is offered, open it under Deploy → Software Catalog and use its Catalog settings.
