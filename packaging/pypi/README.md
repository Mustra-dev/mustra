# mustra

This package reserves the name `mustra` on PyPI. **It contains no functional code.**

[mustra](https://mustra.dev) is an open-source fleet management and endpoint
operations platform: a lightweight Go agent on every device, NATS as the
outbound-only message backbone, and a web console for live inventory, patch
management, and vulnerability data.

Since mustra is written in Go, there may never be anything meaningful to
install from PyPI — this package exists so the name matches the project's
domain rather than belonging to someone else.

- Website: <https://mustra.dev>
- Source: <https://github.com/mustra-dev/mustra>
